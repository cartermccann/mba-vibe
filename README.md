# Mind Body Athletes — vibe look-see

A standalone visual experiment for Mind Body Athletes. It is not a replacement for [mindbodyathletes.com](https://www.mindbodyathletes.com).

Copy and photographs come from the live Mind Body Athletes site and program archive. Founder: Allie Chapman. Palette is Allie’s gold, ink, and paper.

## Run locally

```bash
npm install
npm run dev -- --port 43173
```

Open [http://127.0.0.1:43173](http://127.0.0.1:43173).

Pages: Home, About, Programs, Athletes & Parents, Contact, Privacy, Terms.

The contact form is local-only in this look-see. Submissions stay on the machine and are not emailed.

## Build

```bash
npm run build
```

# Product

## Platform

web

## Stack

Next.js 16, TypeScript, Tailwind CSS 4, shadcn/ui. Standalone visual look-see; does not replace mindbodyathletes.com.

## Users

- **Primary:** Coaches, athletic directors, school and club program leaders evaluating Mind Body Athletes for their teams.
- **Secondary:** Parents and athletes seeking at-home resources (ACTIVE workbook, parent guides, external Heather Experience links).

## Product Purpose

Mind Body Athletes is an Athlete Wellness Initiative that gives coaches science-backed tools to help athletes handle pressure in season and in life. This look-see demonstrates a denser editorial UI in Allie Chapman’s gold / ink / paper palette for Carter McCann’s review.

## Positioning

Regulation precedes performance. The program supports the whole athlete through nervous-system-informed coaching—not generic sports psychology or clinical therapy.

## Voice & Boundaries
